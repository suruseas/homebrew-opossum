# homebrew-opossum

Homebrew tap for [opossum](https://github.com/suruseas/opossum) — run docker
compose projects on Apple's `container` runtime.

```sh
brew install --cask suruseas/opossum/opossum
```

## Reporting problems

The cask in this repository is generated on every release and carries a
`DO NOT EDIT` header, so please don't send changes here — the next release
would overwrite them.

Issues and pull requests belong in the main repository:
<https://github.com/suruseas/opossum/issues>
